####rostopic pub
rostopic pub -1 /turtle1/cmd_vel geometry_msgs/Twist -- '[2, 0, 0]' '[0, 0, 1.8]' // [x,0,0] [0,0,x] makes circular arc
//space is necessary between linear and angular vel
try -2 instead of -1 //-1 is --once(others are not part of syntax), use -r for rate
try the following along with the above command having '-r 10'
rostopic pub -r 5 turtle1/cmd_vel geometry_msgs/Twist -- '[-2,0,0]' '[0,0,-2]' //'r' signifies the rate. so, we can say that the speed of moving forward becomes half as it goes forward and backward but forward is more
//another observation, the time at which the command is passed also makes a difference as '-r' is related to value in Hz. it can be experimented by giving two same commands of same rate but opposite values. the timing of pressing enter for the second command makes all the difference whether the turtle moves forward or backward :D

####rosservice
	args //get args for a service
	call //execute a service
	find
	info
	list //add '-n'rosservice args to get nodes that implement this service
	type
	uri
	node <service> //get the node implementing this service
egs: clear, roshi/get_loggers, roshi/set_logger/level, teleop_turtle/get_loggers, teleop_turtle/set_logger_level, turtle1/set_pen, turtle1/teleport_absolute, turtle1/teleport_relative

rosservice type clear //tell us the it needs no args and gives none
rosservice call clear //clears the path
rosservice call reset //resets the turtle and even changes the version of turtle ;)
